About QuickNotes

QuickNotes is a simple note-taking app designed to help you capture ideas before they disappear.

How to Use QuickNotes

  1. Type your note in the input field.
  2. Click the "Add note" button to save it.
  3. Your notes will appear in the list below.

Features

  • Add notes quickly
  • Keep your notes organised
  • Use keyboard shortcuts

Keyboard Shortcuts

Shortcut Action
Ctrl + Enter Add note
Ctrl + S + D Delete note
